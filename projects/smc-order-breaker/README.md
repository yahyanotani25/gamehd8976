# Order Block vs Breaker Block — 3D motion-graphics short

A 31-second vertical (1080×1920) explainer about Smart Money Concepts,
voiced in Roman Urdu, in the style of the owner's reference video (white
graph paper, maroon titles, popping candles, drawn highlight boxes and
arrows), rebuilt in real 3D with kinetic type, a moving camera,
transitions and full sound design.

Everything is generated by code: no stock footage or images. The only
inputs are the owner's voice-over (`data/vo.mp3`) and their sound effects
library (`/sfx` at the repo root).

## Build the film

Needs Node 20+, ffmpeg, Playwright's Chromium, and Python 3 with
`audio/requirements.txt`.

```
npm install
render/make.sh 3            # 3 parallel render workers -> out/final.mp4
```

`make.sh` collects each scene's SFX cues, synthesises the SFX palette and
music, mixes and masters the soundtrack (`out/mix.wav`, −14 LUFS),
renders the picture at 60 fps (`out/master60.mkv`, lossless) and finishes
it to 30 fps with a 180° shutter (`out/final.mp4`).

## Preview while editing

```
node render/preview.mjs --scenes s2 --range 2.45:11.6:0.25 --sheet 6 --guides --out previews/s2/try
```

writes full-size frames and a labelled contact sheet; `--guides` draws the
layout bands (title, main, captions, platform UI).

## How it fits together

| path | what |
|---|---|
| `docs/STORYBOARD.md` | the beat sheet: every visual and sound event, timed to the words |
| `docs/ENGINE.md` | the scene API and rules |
| `data/words.json` | per-word timings, force-aligned to the voice-over |
| `engine/` | renderer, graph-paper world, camera, post FX (`core.js`), 3D kit (`kit.js`), DOM overlay (`overlay.js`), easing (`anim.js`) |
| `scenes/` | one module per scene + `index.js` (the timeline and its transitions) |
| `audio/` | SFX synthesis, music, mixer |
| `render/` | preview, parallel render, finishing |

Every frame is a pure function of time, so frames render in any order and
in parallel browsers.

## Common changes

- **Retime to a new voice-over**: replace `data/vo.mp3` (and
  `data/script.txt` if the words changed), then
  `python audio/align.py data/vo.mp3 data/script.txt data/words.json`.
  Scenes read word times through `ctx.wt(...)`, so most beats follow;
  re-check hard-coded cue times.
- **Change a sound**: edit the scene's `cues`, or a generator in
  `audio/sfx.py`; per-sound loudness targets are in `audio/mix.py`.
- **Colours / fonts**: `PAL` in `engine/kit.js`, fonts in
  `engine/index.html`.
